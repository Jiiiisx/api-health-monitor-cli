INSTRUKSI MINI PROJECT
TRIAL STUDY CLUB BACKEND BASIC
Buatlah sebuah proyek backend sederhana yang dapat melakukan operasi
CRUD (Create, Read, Update, Delete) yang dapat dioperasikan ke sebuah
struktur data object di dalam array yang akan digunakan sebagai
penyimpanan data. Mini Project dikerjakan secara individu.
A. KRITERIA WAJIB

1. Implementasi Operasi CRUD
Program harus memiliki fungsionalitas dasar CRUD yaitu Create
(menambah data), Read (menampilkan data), Update (mengubah
data), dan Delete (menghapus data). Minimal 4 Operasi CRUD.
2. Penggunaan Array of Objects
Data utama dalam aplikasi harus disimpan dalam bentuk Object
yang berada di dalam Array agar data lebih terorganisir.
3. Penerapan Modularisasi
Kode program tidak boleh menumpuk di satu file. Wajib
menerapkan pemisahan file (modularisasi) menggunakan sistem
import dan export.
4. Alur I/O Node.js
Aplikasi harus bisa menerima input data dari program dan
memberikan hasil output ke layar terminal.
5. Penerapan Logika Dasar & Variabel
Wajib menggunakan const atau let (bukan var), serta
mengimplementasikan logika percabangan (seperti if/else atau
switch) dan perulangan.
6. Penggunaan Arrow Function
Definisi fungsi di dalam program wajib menggunakan sintaks ES
Arrow Function () => {}.
B. KRITERIA BONUS

Penggunaan Array Methods
Memanfaatkan metode iterasi, transformasi, atau filter data
tingkat lanjut minimal 2 buah, seperti .map(), .filter(),
.reduce(), .some(), atau .every() untuk manipulasi data
CRUD.
2. Penerapan Spread Operator
Menggunakan Spread Operator (...) untuk menyalin data,
menggabungkan elemen array, atau menggabungkan properti
objek tanpa melakukan mutasi langsung pada data awal.
3. Penerapan Destructuring Assignment
Menggunakan Destructuring untuk mengekstrak nilai spesifik dari
Array (berdasarkan indeks) atau Object (berdasarkan nama
properti) ke dalam variabel yang lebih rapi.
4. Format Output Bersih
Menggunakan Template Literals dengan backticks (`) dan
operator ${} untuk mencetak hasil output teks ke terminal agar
lebih bersih tanpa operator string +.
5. Validasi Program
Menambahkan validasi logika sederhana menggunakan operator
perbandingan (seperti === atau !==) dan operator logika (&&, ||,
!) untuk mencegah error saat pengguna memasukkan input yang
salah (misalnya menghapus ID tugas yang tidak ada).
